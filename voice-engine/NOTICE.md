# Local neural speech assets

The Kokoro model and speaker style assets are licensed under Apache-2.0.
See `LICENSE-KOKORO.txt`.

- `female.bin`: Kokoro `af_heart` speaker style from `kokoro-js` 1.2.1.
- `male.bin`: Kokoro `am_michael` speaker style from `kokoro-js` 1.2.1.
- `phonemize.mjs`: upstream Kokoro JavaScript phoneme preprocessing, from
  https://github.com/hexgrad/kokoro/blob/main/kokoro.js/src/phonemize.js
- `vocab.json`: Kokoro phoneme vocabulary distributed by `kokoro-onnx`,
  https://github.com/thewh1teagle/kokoro-onnx/blob/main/src/kokoro_onnx/config.json

Kokoro authors: hexgrad and contributors. JavaScript implementation: hexgrad,
Xenova and contributors. `kokoro-onnx`: thewh1teagle and contributors (MIT).
These are pre-trained synthetic speaker styles; they do not clone a game user's
voice. The game displays them as Female and Male.

The ONNX model is downloaded separately into `.speech-models/`; it is not served
to browsers. CPU inference uses ONNX Runtime (MIT). Phoneme conversion uses the
`phonemizer` package with its bundled eSpeak-NG data/engine. Its upstream license
notices remain distributed in that dependency. eSpeak creates phonemes only;
the audible waveform is generated by the neural Kokoro model.
